# 🛠️ WorkBuddy 工具网站集合

一个包含 12 实用工具网站的前端项目集合，全部使用 HTML、CSS、JavaScript 实现，无需后端依赖。

## 📋 包含的工具

1. **单位转换器** - 长度、重量、温度、货币等实时转换
2. **Base64 编码/解码** - 文本/文件转换、批量处理、图片预览
3. **UUID/随机字符串生成器** - UUID v4/v7、自定义长度、批量生成
4. **网址/参数解析工具** - URL 参数提取、解码、查询字符串生成
5. **颜色转换器** - RGB/HEX/HSL/HSV 互转、调色板、对比度检测
6. **字符计数/阅读时间** - 实时字数、行数、词频统计、阅读时长估算
7. **HTML/CSS/JS 在线格式化/压缩工具** - 代码编辑器、一键格式化、压缩混淆
8. **随机抽选/转盘** - 自定义选项、动画转盘、权重设置、分享结果
9. **ASCII 艺术生成器** - 图片转字符艺术、字符集自定义、下载功能
10. **字体预览与对比** - 实时预览多种字体、字体下载、CSS 代码生成
11. **在线计时器/闹钟** - 多个计时器、倒计时、闹钟声、键盘快捷键
12. **视频链接 + 字幕提取器** - 粘贴视频网址自动提取字幕（支持 YouTube、Bilibili 等）

## 🚀 快速开始

```bash
# 克隆项目
git clone <your-repo-url>
cd tools-website

# 安装依赖 (如果有 npm)
npm install

# 直接打开 index.html 或使用 live server
npx serve
```

## 💻 开发说明

- **技术栈**：HTML5、CSS3、Vanilla JavaScript
- **无依赖**：所有工具纯前端实现，无需后端服务
- **响应式**：移动端和桌面端均可良好显示
- **本地存储**：部分工具使用 LocalStorage 保存历史记录

## 🛠️ 添加新工具

每个工具位于 `tools/` 目录下，包含：
- `index.html` - 页面结构
- `style.css` - 样式文件
- `script.js` - 逻辑实现

## 📦 构建与部署

```bash
# 使用 GitHub Pages 部署
```
